1.  Before Running the Simulated Tests to create users data , make sure you Initialised the database tables
    a . To create database and tables in it ( cart , products , orders , payments ) 
          => python database/init_db.py
    b . To clean the databaese or to delete tables from database
          => python database/clean_db.py

2.  Run the complete 55-order visual pipeline:
        .\venv\Scripts\python run_simulation_pipeline.py

        # Or in Fast-Forward mode:
        .\venv\Scripts\python run_simulation_pipeline.py --fast

        # Or for a quick 10-order test:
        .\venv\Scripts\python run_simulation_pipeline.py --count 10 --fast
